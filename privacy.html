นโยบายความเป็นส่วนตัว (เครื่องมือ "มองข้ามโลก autopost")

เครื่องมือนี้ทำงานบนคอมพิวเตอร์ของเจ้าของช่องเท่านั้น และใช้เพื่ออัปโหลดวิดีโอของช่องมองข้ามโลกไปยังบัญชีของช่องเอง

  • ข้อมูลที่เข้าถึง: สิทธิ์อัปโหลดวิดีโอ (YouTube youtube.upload) และอ่านชื่อช่องเพื่อยืนยันว่าเป็นช่องที่ถูกต้อง (youtube.readonly) รวมถึงสิทธิ์โพสต์ลงเพจ Facebook, Instagram และ TikTok ของช่อง
  • การเก็บข้อมูล: โทเคนการเข้าถึงเก็บไว้ใน macOS Keychain บนเครื่องของเจ้าของช่องเท่านั้น ไม่มีเซิร์ฟเวอร์กลาง ไม่ส่งต่อ ไม่ขาย และไม่แชร์ข้อมูลให้บุคคลที่สาม
  • การใช้ข้อมูล: ใช้เพื่ออัปโหลดวิดีโอและข้อความที่เจ้าของช่องเตรียมไว้เท่านั้น ไม่อ่านหรือเก็บข้อมูลของผู้ชม
  • การถอนสิทธิ์: ถอนได้ทุกเมื่อที่ Google Account → Third-party access, การตั้งค่าแอปของ Facebook และ TikTok แล้วลบรายการ autopost-* ใน Keychain
  • การใช้ข้อมูลจาก Google API เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use และ YouTube Terms of Service

Privacy Policy (English)

"มองข้ามโลก autopost" runs only on the channel owner's computer and uploads the channel's own videos to the channel's own accounts. It requests YouTube upload and read-only channel access (plus equivalent posting permissions on Facebook, Instagram and TikTok). Access tokens are stored only in the owner's macOS Keychain; there is no server, and no data is sold, shared or transferred to third parties. No viewer data is collected. Access can be revoked at any time at Google Account permissions. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. By using YouTube features you agree to the YouTube Terms of Service and Google Privacy Policy.
